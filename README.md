*Calculadora Avanzada en Python*

Calculadora de terminal con soporte para funciones matemáticas, variables y un parser de expresiones seguro (sin eval()).


Características
Operaciones básicas: + - * / // % **
Funciones matemáticas: sin, cos, tan, sqrt, log, log10, exp, factorial...
Constantes: pi, e, tau
Variables persistentes: x = 5 * 3 y luego x + pi
Historial de operaciones
Manejo de errores con mensajes claros (división por cero, dominio inválido, etc.)
